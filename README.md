# Torrance Buzz Banner Builder

A brand-locked banner generator for The Torrance Buzz Weekly.

## Version 1
- Fixed 1200 × 150 PNG output
- Locked TBW blue and typography system
- Approved layouts, accents, and icon treatments
- Live browser preview
- One-click PNG export
- Style reference upload stored locally in the browser
- No-cost Smart Assist by default
- Optional AI enhancement can be added later without changing the core generator

## Run locally
1. npm install
2. npm start
3. Open http://localhost:3000

## Railway
Deploy this repository as a Node service. No database is required.
